AI / MCP

接入 Claude Code执行下方命令，把 magicdevx 注册为 MCP 服务 
claude mcp add magicdevx -- /Applications/MagicDevX.app/Contents/MacOS/magicdevx-mcp
其他 MCP 客户端 
{
  "mcpServers": {
    "magicdevx": {
      "command": "/Applications/MagicDevX.app/Contents/MacOS/magicdevx-mcp"
    }
  }
}
允许 shell 工具AI 可以执行任意 adb shell 命令
AI 截图默认长边截图尺寸即点击坐标空间
