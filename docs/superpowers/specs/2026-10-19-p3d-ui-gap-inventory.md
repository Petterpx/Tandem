# P3d 附录：工作台界面差异清单

Audit of the SwiftUI app (commit fca304c) against `docs/superpowers/design/mockups/` (primarily `Workspace.dc.html`). App paths are relative to `App/`. Line numbers are as of fca304c. Decisions in the spec (`2026-10-19-p3d-workspace-ui-design.md`) override anything here; §6 items marked P3e are out of scope for P3d.

## 0. Summary
- **Shared style layer:** `Theme.swift` exists (dynamic light/dark colors, ~190 uses), but there are no custom ButtonStyle / ToggleStyle / card modifier / section header / chip. Everything is stock SwiftUI: default bordered buttons, `.borderless`, `.switch .mini` toggles, `.segmented` tab picker, `.menu` pickers, `.roundedBorder` fields, `List` for sidebar / history / log.
- **Theme values off-spec** (`Theme.swift:7-19`): sidebar EEF0F3 (design F4F4F6; EEF0F3 is the design's *canvas*), canvas E8EAED (EEF0F3), canvasDot opaque CFD3D9 (design rgba(0,0,0,0.05)), textPrimary 1C1E21 (1D1D1F), textSecondary 6B7280 (6E6E73), separator DADDE2 (E5E5EA), success 1E9E5A (1F9D55).
- **Type 1–2pt small:** macOS `.caption` = 10pt, `.callout` = 12pt. Section headers use `.caption.semibold` (10pt) vs design 11pt semibold tracking 0.04em; row labels `.callout` (12) vs 13. ~50 `.caption`, ~29 `.callout` uses.
- **Layout:** `WorkspaceView.swift:16-29` HSplitView, sidebar 190–280 (ideal 220) vs 232; right panel 260–380 (ideal 300) vs 372; bottom row 150 vs 168, split 50/50 (`:115-117`) vs log column 372 aligned under right panel; bottom bg Theme.panel (`:119`) vs #FFFFFF.
