打开输入注入权限

小米 / 红米（MIUI、HyperOS）
  1. 设置 → 更多设置 → 开发者选项
  2. 打开「USB 调试（安全设置）」
  3. 按系统提示确认（部分机型需登录小米账号并插入 SIM 卡）
OPPO / 一加（ColorOS） 开发者选项 → 打开「禁止权限监控」
vivo / iQOO（OriginOS） 开发者选项 → 打开「USB 模拟点击」
选项名称可能随系统版本变化，以手机上的实际选项为准。其他品牌请在开发者选项中查找与「USB 调试」「模拟点击」相关的开关。
